## Important scope note

"All programming languages" is not a finite, universally agreed dataset. Thousands of experimental,
esoteric, internal, dialect, and historical languages exist. This pack deliberately uses the English
Wikipedia **List of programming languages** as its catalogue boundary: notable current/historical executable
languages and executable DSLs. That source excludes markup languages, esoteric languages, and BASIC dialects.

## Do not combine these metrics blindly

- **GitHub Innovation Graph**: public GitHub activity by unique developer-language pushers, quarterly, by economy.
- **Stack Overflow 2025**: self-reported language use among survey respondents.
- **TIOBE**: a popularity/search-interest index.
- **Country table**: respondent sample composition, not national developer population.
- **Gender**: no language-by-gender values are fabricated. Use raw survey microdata and publish sample sizes if CODARIS later builds a demographic cross-tab.

## Suggested CODARIS UI

For each language page, show:
1. Language name and A-Z catalogue position.
2. GitHub activity rank/count when available.
3. Stack Overflow reported-use percentage when available.
4. TIOBE rank/rating when available.
5. A "What this metric means" tooltip.
6. Country data only when the source provides adequate coverage.
7. Demographics only with explicit source, sample size, year, and non-response categories.
