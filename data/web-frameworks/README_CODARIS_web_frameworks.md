# CODARIS Web Frameworks & Technologies Research Pack

Generated: 23 September 2026

## Scope

This pack contains **631 web frameworks and closely related web technologies**.

It intentionally keeps a `kind` / `type` field because the web ecosystem does not consist only of frameworks:
- React is a UI library.
- Node.js, Deno and Bun are runtimes.
- WordPress and Drupal are CMS platforms.
- Tailwind CSS and Bootstrap are styling/UI frameworks.
- Next.js, Angular, Django, Laravel, Rails, Spring Boot, Phoenix and many others are application frameworks.

For CODARIS, it is better to place these under a broad **Web Frameworks & Technologies** directory and show the technical type prominently.

## Included research

- Broad A-Z catalogue covering JavaScript/TypeScript, Python, PHP, Ruby, JVM, .NET, Go, Rust, Elixir/Erlang, Scala, Clojure, Haskell, Perl, C/C++, Swift, Dart, Lua, Crystal, Nim, R, Julia, OCaml and other ecosystems.
- CSS/UI frameworks and component systems.
- Static-site/documentation frameworks and generators.
- Stack Overflow Developer Survey 2025 usage rankings for the technologies it measured.
- Selected State of JavaScript 2025 usage and satisfaction metrics.
- W3Techs website-usage snapshot for React, Vue.js and Angular dated 2026-09-23.
- Survey geography, methodology, demographic cautions and source provenance.

## Measurement rules

Do **not** average or merge the popularity columns into one score.

1. **Stack Overflow 2025**: self-reported extensive use during the prior year among respondents to its web-framework/technology question.
2. **State of JS 2025**: JavaScript-community survey, with its own denominator and definitions.
3. **W3Techs**: detected use on websites, not a developer survey.
4. **Country table**: survey sample geography only, not framework-by-country usage.
5. **Gender**: no per-framework male/female figures are fabricated. A proper demographic analysis requires explicit cross-tabs, sample sizes and preservation of non-binary/non-response categories.
